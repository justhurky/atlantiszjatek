# Képek helye

Ide kerülnek a játék képei. A fájlnevek a `src/stages.js` fájlban szerepelnek:

| Fájl | Mire kell |
| --- | --- |
| `statues/herakles-es-akheloosz.jpg`, `statues/apollon.jpg`, `statues/tancolo-nimfak.jpg` | Görög szobrok a fotós feladathoz: Héraklész és Akhelóosz (F. J. Bosio, Louvre), Apollón, táncoló nimfák |
| `szechenyi-feju-poszeidon.jpg` | „Ki látható a képen?": a Széchenyi-fejű Poszeidón (mindkét válasz helyes) |
| `hadesz.jpg` | Istenek felismerése: Hádész a háromfejű Kerberosszal |

Ha egy kép hiányzik, a játék egyszerűen kihagyja, nem törik el.
